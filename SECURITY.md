# Security policy

Report a suspected vulnerability privately to the repository maintainers with reproduction steps, affected version, impact, and any suggested mitigation. Do not include secrets, personal information, or exploit data in a public issue.

The latest tagged release receives security fixes. Reports are acknowledged within five business days, triaged before public disclosure, and coordinated with the reporter where practical. Dependency alerts rated high or critical block a release until fixed, removed, or documented as not affecting the production bundle.
